# Dom

1. Всегда общайся с пользователем на русском языке.
2. Все вопросы задавай в интерактивном режиме (через инструмент question), а не текстом в ответе.
3. Когда решаешь issues отмечай в нем самом выполненные пункты.

## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Defaults: the five canonical role names as literal label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
