# 08: Автокомплит в демке

Status: ready-for-agent
Blocked by: 07

Компонент автокомплита переезжает из теста в `demo/autocomplete.ts`; демка задач использует его вместо простого поля, тест импортирует компонент из демки.

Поведение: ввод фильтрует подсказки (по подстроке), Enter вызывает `onpick` с введённым текстом, клик по подсказке (`mousedown`, чтобы успеть до blur) — с текстом подсказки; после pick поле очищается и dropdown закрывается; пустой результат фильтрации скрывает dropdown.

## Acceptance

- `npm test` — тесты автокомплита тянут `../demo/autocomplete.ts`
- демка: замена текста существующей задачи в подсказках видна без перезагрузки (items — computed от todos)
- дубликаты задач не создаются

## Comments

Резолюция: 42/42 теста, демка проверена в браузере (фильтрация, Enter-добавление, клик по подсказке с дедупликацией, реактивные items). Дизайн-заметка: подсказки в demo — существующие тексты задач; для продакшн-компонента источник items передаётся снаружи.

Правка после ревью (UX): в первой версии клик по подсказке сразу вызывал onpick — но подсказки были из существующих задач, дедупликация молча их съедала, и клик выглядел «ничего не происходит». Переделано на классический autocomplete: клик подставляет значение в инпут, добавление — Enter или кнопка «Добавить» (вернул). Компонент стал управляемым: query — внешний Signal, onsubmit вместо onpick. Подсказки — пресеты + существующие задачи (Set против коллизий ключей). 43/43 теста, цикл «клик → подстановка → Добавить» проверен в браузере.
